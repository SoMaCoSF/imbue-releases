# imbue-releases

Imbue release downloads — **binary builds only**.

Each release ships the Windows binaries (`Imbue-Setup-*.exe`, `Imbue-Update-*.exe`, `imbue-win-gui.zip`) with install notes. The Imbue source code is closed and lives in a private repository; the "Source code" archives GitHub lists on this page contain only this README.

Get Imbue: https://somacosf.gumroad.com/l/imbue
